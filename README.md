## 🌌 О проекте

**Classic Station 14** — русскоязычный MRP-сервер, созданный для тех, кто скучает по ламповой атмосфере Space Station 14 образца 2023 года. Мы бережно восстановили классическую сборку, убрали всё лишнее и сделали упор на динамичный геймплей и живой ролевой отыгрыш:

| Особенность | Описание |
| :--- | :--- |
| <img src="https://classicstation14.com/assets/sprites/toolbox-red.png" width="32" /> **Старый инвентарь** | Привычная нижняя панель, карманы, пояс и удобные окна сумок и аптечек без сеточного тетриса. |
| <img src="https://classicstation14.com/assets/sprites/firstaid.png" width="32" /> **Классическая медицина** | Быстрое лечение бинтами, мазями, базовой химией, криокапсулами и капсулами клонирования — без затянутых операций. |
| <img src="https://classicstation14.com/assets/sprites/id-sec.png" width="32" /> **Таймеры ролей ÷ 4** | Все таймеры открытия закрытых профессий снижены **в 4 раза** — легко открывайте любимые отделы без десятков часов гринда. |
| <img src="https://classicstation14.com/assets/sprites/pda-captain.png" width="32" /> **Своя классическая Вики** | Полная база знаний под сборку 2023 года: [Корпоративный закон (КЗ)](https://wiki.classicstation14.com/Корпоративный_закон.html), [СРП](https://wiki.classicstation14.com/Стандартные_рабочие_процедуры.html) и [Химия на 289 веществ](https://wiki.classicstation14.com/Химия.html). |
| <img src="https://classicstation14.com/assets/sprites/ian.png" width="32" /> **Право на ошибку и чистый РП** | За случайные игровые ошибки по незнанию администрация **не банит** — всё решается строго в IC. Полный запрет на 18+/ERP и отсутствие ТТС. |

## 🔧 Участие в разработке и отправка Pull Request (PR)

Мы рады помощи сообщества в поддержании стабильности и чистоты классической сборки 2023 года! Перед созданием Pull Request ознакомьтесь с нашими правилами:

1. 🚫 **Новые фичи НЕ добавляются.**  
   Наша главная цель — сохранить аутентичный геймплей 2023 года. Поэтому Pull Request'ы рассматриваются **исключительно на исправление багов**, крашей, уязвимостей, проблем перевода и недоработок существующих механик.
2. 🤖 **Вайбкодинг НЕ запрещён.**  
   Вы можете свободно использовать любые ИИ-инструменты и ассистентов для поиска и исправления багов. Главное — качество и работоспособность итогового исправления.
3. 🧪 **Обязательное тестирование вами.**  
   Все исправления перед отправкой PR **должны быть лично протестированы вами** на локальной сборке. Убедитесь, что проект компилируется без ошибок, а ваш фикс действительно решает проблему и ничего не ломает.
4. 🏅 **Роль Контрибьютора.**  
   За существенную помощь проекту и принятые баг-фиксы вы получите почётную роль **`🔧 Контрибьютор`** на нашем [Discord-сервере](https://discord.gg/A6pFnBgD9G)!
